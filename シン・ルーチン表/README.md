# シン・ルーチン表

タスク管理HTML / TaskBoard v1.0

自己完結したHTMLです。外部フォント・CDN・外部スクリプトへの依存はありません。

- 未対応（無色、リマインド時のみ赤系）・対応中（パステル青）・完了（グレー）の3列
- ドラッグ、またはカードメニューで状態変更
- 各列は予定時刻順。未対応の期限超過カードを赤く表示
- カードの＋で備考を展開。追加・編集・削除
- 担当者①・②を2名まで設定。時間・タスク・担当者を横並びにした薄いカード
- ブラウザのライト／ダーク設定に追従
- 日付切替、検索、JSONバックアップと追加復元
- 初回の自分の名前登録、追加・編集画面の「自分が担当」、担当者本人のタスクの絞り込み

## 利用

`TaskBoard_v1.0.html`をWindowsのEdge／Chromeで開きます。個人用データはブラウザに保存されます。

共同利用では各PCの「共有設定」で同じ共有フォルダを選択してください。`TaskBoard_Data`内に変更ごとのJSONを保存し、画面を開いている間に約3秒ごとに読み込みます。HTMLを配布するだけではデータ共有になりません。画面を閉じている間の通知はありません。

## 自分の名前と担当検索

初回表示で自分の名前を登録します。名前は共有ログに含めず、各ブラウザの個人設定として記憶します。画面右上の名前ボタンから変更できます。追加・編集画面の各「自分が担当」で担当者①または②に入力し、検索横の同名ボタンでどちらかの担当欄が登録名と一致するタスクに絞り込みます。キーワード検索でも両方の担当者名を検索できます。

既存の担当は担当者①として保持し、担当者②がない過去のタスクやバックアップも読み込めます。2名の担当情報は個人用保存・共有フォルダ・バックアップのすべてで保存します。共有する全員が2名対応版のHTMLを使用してください。

## カードの表示

大きな画面では時間・タスク・担当者・操作ボタンを横並びにし、上下の余白と文字サイズを抑えています。2名の担当者は右側に①・②の順で表示し、備考は＋を押したときに展開します。長いタスク名は折り返し、担当者名は省略表示時にカーソルを重ねると全文が見られます。幅の狭い画面では担当者をタスク名の下に配置します。

カードの操作メニューは前面に表示し、他のカードや列のスクロール枠に隠れないようにしています。画面下端に近いときは上側へ開き、画面外へはみ出さない位置に調整します。一覧のスクロール・画面サイズ変更・データ更新時にはメニューを閉じます。

## 同時更新

変更を追記する方式で、共有ファイル全体の上書きを避けています。タスク単位・項目単位で変更を統合し、同一項目の同時変更は操作番号と操作IDの順で一意に解決します。削除を記録したタスクは遅延した編集で復活しません。共有ログファイルは追記運用のため、運用中に手作業で削除・書き換えないでください。
