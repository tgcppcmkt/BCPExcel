業務量モニター3.0tag HTML版 v0.8.3

■ 最初に試す
1. ZIPを「すべて展開」してください。HTMLと4つのJSを同じフォルダに置きます。
2. WorkloadRanking.htmlを通常のMicrosoft Edgeで開きます。
   右クリック →「プログラムから開く」→ Microsoft Edgeでも開けます。
   各PCのローカルフォルダへ展開して開く形を想定しています。
3. 画面上部の「設定」で「共有」「未読」「フラグ」「振分表」の4項目を選択します。
   「共有」は全員が使う同じ共有フォルダ、「未読」「フラグ」はそれぞれ日付フォルダの親を選びます。
   「振分表」は .xlsx / .xlsm のExcelを選択します。各ボタンの右横に選択先の名前を表示します。
   記憶済みなら再選択は不要です。未設定の項目は「ログ集計」を押したときに案内します。
4. 「ログ集計」で共有情報を更新し、保存待ちがあれば再試行します。
   記憶した共有先などに再許可が必要な場合は、表示された確認で許可してください。
   共有先を変更するときは「設定」の「共有」を使います。「再読み込み」ボタンはありません。
5. 更新後、未読CSV → フラグCSVの順に選択し、そのまま集計します。
   更新に時間がかかるなど、ブラウザが追加のクリックを必要とする場合だけ、
   「ログ集計を続ける」の「CSVを選択」を押します。許可の確認が必要なら「許可を確認」を押します。
   途中で選択や継続をキャンセルした場合は、CSVの記憶と入力中のサポート欄を保持します。
   更新に失敗した場合はCSV選択を開始せず、エラーを表示します。

手元で試す場合は、業務用とは別の試用フォルダに、未読 / yyyymm / mmdd と
フラグ / yyyymm を作り、サンプルの未読.csv・フラグ.csvを対応するフォルダへコピーします。
yyyymm・mmddには、利用PCの当月・当日を使ってください。
「未読」「フラグ」には、その試用の未読・フラグフォルダを選び、
「振分表」にはサンプルの振分表.xlsx、「共有」にはサンプルの共有フォルダを選択します。
サンプルの件数は「サンプル/試し方.txt」を参照してください。

■ 最新版から引き継いだ処理
・純粋未読、フラグ、未仕分、ランキング、対応余力、検索、チーム絞込。
・担当者の担当CAがすべてコミットになってから、担当者の件数・ランキングを変更。
・担当CAごとに1つの「サポ希望」チェック。そのCAがチェック済みになると有効。
・サポートが3名になったCAの希望は、3人目の投入と同じ共有操作で自動解除。
  人数が減っても希望は自動で戻りません。必要なら再チェックしてください。
・担当者カードのサポート投入状況に赤字で「サポ希望」を表示。
  いずれかの未コミットCAに希望がある場合に表示します。
・担当CAすべてがコミット済みになった担当者カードをグレー表示。取消で通常表示に戻ります。
・CAごとに最大3名のサポート。登録確認は「入力を確定しますか？」、はい／いいえ。
・サポート氏名のツールチップは氏名のみ。氏名クリックによる解除は最新版どおり。
・17時以降は、チェック済みCAのコミットをCAチェック欄に表示。チェック未のCAはそのまま。
・コミット取消、CAチェック、担当者カードとCAカードの数値位置。
・Canvasリンクの末尾に、利用PCの当日の日付 yyyy/mm/dd を追加。
・起動時は集計表示をクリアし、当日の共有履歴を復元。

土日用の別集計は、この版には追加していません。

■ HTML版でのファイル選択
Windowsのパス文字列を指定して自動アクセスする方式から、ブラウザで選択する方式に変更しました。
ファイル・フォルダの選択許可はブラウザの許可です。管理者権限を使う処理はありません。
通常のEdgeで、フォルダ選択・読込・書込のAPIが利用可能な環境が必要です。
会社のポリシーで利用できない場合は、設定を管理担当へ確認してください。

前回のファイルと共有フォルダをブラウザに記憶します。
再起動後に読込許可が必要な場合は、表示された確認画面で許可してください。
共有先の再許可・再接続・再読込は「ログ集計」から行います。
振分表は .xlsx / .xlsm に対応します。.xls / .xlsb / パスワード付きブックは対象外です。
Excel自体は起動しません。保存されたセルの値を読み、マクロ・数式の再計算は行いません。
数式結果が未保存の場合は、Excelで開いて保存したコピーを選択してください。
Excelを開いて編集している場合、その未保存の変更は取り込まれません。

ハイパーリンク、URL文字列、URLが直接書かれたHYPERLINK数式を読み取ります。
他セル参照や文字列結合を使ったHYPERLINK数式など、URLを確定できないリンクは通知します。
その場合は、振分表のリンク欄をURL文字列か通常のハイパーリンクにしてください。
件数の集計は行い、取得できなかったリンクは未設定になります。

CSVはUTF-8、Shift-JIS、UTF-16を既存設定に合わせて読み取ります。
ExcelがCSVを開いている場合の読込可否は、Excel・共有先・ブラウザの制限に依存します。
以前のWindows補助処理によるロック回避はHTMLでは使用できません。
読込できないときはCSVを閉じるか、別名コピーを選択してください。
取込エラーが出た場合は、取込前の集計データを保持します。

「設定」の「未読」「フラグ」で、未読とフラグの日付フォルダの親を記憶します。
設定ボタンは「共有」「未読」「フラグ」「振分表」の4つで、常に表示します。
右横に共有・未読・フラグのフォルダ名、振分表のExcelファイル名を表示します。
長い名前は省略し、カーソルを合わせると名前全体を確認できます。
未読：親フォルダ / yyyymm / mmdd、フラグ：親フォルダ / yyyymm。
当日・当月のフォルダをCSV選択画面の初期位置に使います。
「ログ集計」からのCSV選択でも、この親フォルダ設定をそのまま使います。
集計時も当日・当月フォルダのCSVであることを確認します。

workload-config.jsには、列設定・シート名・文字コード・対応余力など、集計に使う設定を残しています。
HTML版では使わない paths の3項目と folderFormat を削除しました。パス文字列の入力は不要です。
ファイル・親フォルダ・共有先は画面で選択し、ブラウザに記憶します。初回の選択は引き続き必要です。
列やシート名を変える場合は、従来どおりworkload-config.jsを修正してください。
未読 C/E/H/M/N/O/R、フラグ C/E/F、振分表 C/E/F/K/L/M は最新版の設定どおりです。

■ 複数人での共有
サポート・CAチェック・サポ希望・コミット操作を、共有フォルダ内の
WORKLOAD_HTML_DATA / yyyymmdd / op-h-操作番号.json に保存します。
全員が同じフォルダへ接続してください。各PCのローカルフォルダでは、他のPCとは共有されません。
共有フォルダへ書き込めることを確認してから、サポート・チェック・コミットを有効にします。
「ログ集計」には4項目の初期設定と共有情報の更新が必要です。取込済みデータの検索・リンク表示は従来どおりです。

操作ごとに別ファイルを作り、他の利用者のファイルを上書きしません。
通常は約3秒ごとに共有を確認します。回線や保存状況により表示の反映は遅れることがあります。
同じCAの操作が重なる場合、全員で同じ順序に並べて適用します。
「同じ氏名の重複」「4人目の投入」「古い画面からの取消」など、反映できない操作は理由を表示します。
一度見えた状態が、遅れて届いた同時操作の反映により変更される場合もあります。
同じCAで競合の表示が出た場合は、最新状態を確認して必要な操作を行ってください。
「設定」の下で未反映の理由を確認できます。

当日の操作ファイルは追記用です。使用中に編集・削除・置換しないでください。
新しく読んだファイルの形式を検査し、保存済みのファイルは小分けに更新有無を確認します。
変更・破損・削除を検知した場合は、共有更新を止めて理由を表示し、元の履歴は上書きしません。
過去の日付フォルダも保持します。旧版のOLDフォルダへの移動処理はありません。
多数の操作がある共有フォルダでの実際の速さは、社内環境で確認してください。

■ 保存が失敗したとき・画面を閉じるとき
確認済みの操作を先に端末内へ退避し、共有保存の結果を確認するまで「保存待ち」として扱います。
失敗した操作は、自動確認時または「ログ集計」の共有更新時に、同じ操作番号のまま再送します。
端末内への退避にも失敗した場合は、操作を確定せずエラーを表示します。
保存待ちがあるときは、完了まで画面を開いてください。
ブラウザから閉じる際に警告を要求します。警告の表示・文言はブラウザの仕様によります。
閉じた画面から書込処理を続ける補助プログラムはありません。
閉じた場合は、同じHTMLの場所・Edgeプロファイルで開き、同じ共有先へ再接続して再送してください。
ブラウザの保存データを消す、別プロファイルで開く、HTMLを移動する場合、保存待ちを復元できないことがあります。
保存が終わっていない間は、それらを行わないでください。
まだ登録確認をしていない入力文字は共有保存・退避の対象外です。閉じる前に確定または取消してください。

「共有履歴を出力」「保存待ちの控えを出力」のボタンは廃止しました。
通常のCSVファイル名と「共有先／接続済み」の表示は省きます。
エラー・保存待ち・未反映の理由は「設定」の下に表示します。
「設定」は常に表示し、共有・未読・フラグ・振分表と選択先の名前を横並びにしました。
画面幅が狭い場合は、はみ出さないように折り返します。
「再読み込み」は共有情報の更新、共有先の再許可、保存待ちの再送を行います。
未読・フラグのCSV集計は引き続き「ログ集計」から行います。
保存待ちの退避・再送処理は従来どおり維持しています。

■ 旧版の当日履歴を引き継ぐ場合
旧版を全員が停止してから、旧版の当日 yyyymmdd.json があるフォルダを共有先として選択します。
当日JSONを基準として読み取り、HTML版の追加操作をWORKLOAD_HTML_DATAへ保存します。
旧版JSONは変更しません。旧形式の当日JSもデータとして読み、プログラムとしては実行しません。
HTML版と旧版を同じ共有先で同時に使用しないでください。
旧版JSONを更新・新規作成・置換した場合は停止を通知します。旧版を止め、全員がHTMLを開き直してください。
途中で基準JSONを差し替える移行作業は避け、利用開始前に基準をそろえてください。
不要なら、HTML版専用の新しい共有フォルダを選択して、その日から開始できます。

■ ライト／ダーク表示
ブラウザがWebページへ通知するライト／ダーク設定に、画面の配色が自動で追従します。
ライト時は従来の配色を維持します。「共有」はライト／ダークとも他の設定ボタンと同じ見た目です。
ダーク時は黒系の背景とチャコールのカード、落ち着いた緑のアクセントを使います。
全体残件数とログ集計・確認ボタンは深い緑、上位の順位は薄緑の背景と黒に近い数字で表示します。
通常の文字と件数は白系、補足はグレー系とし、明るい枠線で入力欄・ボタンを区別します。
サポ希望・未チェック・エラーは赤系、チェック済・余力は緑系、コミット済はグレーを維持します。
色の切り替え用のJavaScript、タイマー、共有ファイルへの書き込みは追加していません。
ブラウザのツールバーや独自テーマの色を、そのまま画面へ取り込む機能ではありません。
Edgeの設定だけで切り替わらない場合は、Windows側のライト／ダーク設定も確認してください。
